vision: >
  SmartGit は、企業から個人ユーザーまで、誰にとっても Git が扱いやすく、効率的で、力を発揮しやすいものである未来を目指しています。大規模なソフトウェアプロジェクトに取り組む企業、アプリを開発する開発者、MOD を作るゲームユーザー、複数の顧客を支えるフリーランスなど、どのような立場でも作業を進めやすくすることが SmartGit の役割です。私たちは Git をシンプルにし、さまざまなニーズに対してより賢く機能するよう磨き続けています。

history1: >
  Syntevo は 2000 年代初頭、創業者の Marc Strapetz と Thomas Singer が自分たち自身で使いたいと思える高品質な開発者向けツールを作る、というシンプルな考えから始まりました。SmartCVS と SmartSVN から出発した取り組みは、2009 年に登場した SmartGit へと発展し、今では世界中の数十万人の開発者に利用されています。

history2: >
  20 年以上にわたり、Syntevo は独立性と集中力、そして丁寧なものづくりを大切にしてきました。ソフトウェア開発の世界が集中型システムから分散ワークフローやクラウド連携へ移っても、流行を追うのではなく、正確で信頼でき、本当に役立つツールを作るという姿勢は変わっていません。

history3: >
  現在も Syntevo は、創業時から会社を形づくってきた品質、明快さ、開発者中心の考え方を守りながら、SmartGit を磨き続け、新しい技術の可能性を探っています。
