SmartGit 25.1は、AI支援、メタデータ、ワークツリー、LFS、プルリクエスト処理に関する実用的なツール改善に焦点を当てています：
- AIによるコミットメッセージの生成、言い換え、自動スタッシュ説明
- 選択可能な名前空間を持つGit Notesの完全なUI対応
- より安全でブランチを意識したワークツリーのチェックアウトと管理コマンド
- LFSポインター/未展開状態の明示的な表示と高速なLFSリフレッシュ
- 日常のGit作業の摩擦を軽減するその他の改善

***

# **AI統合**

# コミットメッセージの生成と言い換え

{{<screenshot alt="SmartGit 25.1 AIコミットメッセージ生成 - @aiプレースホルダーとバックグラウンド処理" src="ai-rewording.png">}}

---

SmartGitに綺麗なコミットメッセージを作成させましょう。オンデマンドで生成するか、今すぐコミットしてコーディングを続けながらAIに仕上げを任せることができます。

* **クリックして生成** -- コミットメッセージビューまたはコミットダイアログで、AIアクションをクリックすると、変更に対する明確で規約に沿ったメッセージが生成されます。
* **`@ai`によるバックグラウンドモード** -- メッセージとして**`@ai`**と入力してコミット。作業を続けてください。AIの結果が届くと、SmartGitがプレースホルダーを適切なメッセージに**置き換えます**。
* **WIPフレンドリー** -- **WIP**（*work in progress*）プレースホルダーで素早くコミット。SmartGitが後で洗練されたサマリーに**書き換える**ので、履歴が整理されたままになります。
* **非破壊的** -- コードはそのまま。コミットメッセージのみが更新されます。

{{< link url="https://docs.syntevo.com/SmartGit/Latest/Manual/GUI/AI-Commit-Messages" display="詳細を見る" >}}

# 自動スタッシュ説明

{{<screenshot alt="SmartGit 25.1 自動スタッシュ命名 - ブランチビューでのAI生成説明" src="ai-stashing.png">}}

---

入力を省略しながら、スタッシュを検索可能に保ちます。

* **自動説明** -- **AI生成スタッシュメッセージを作成**を有効にして、メッセージなしでスタッシュ。SmartGitが明確なサマリーを作成します。
* **一貫した名前** -- **ブランチ**と**グラフ**のスタッシュには、変更に基づいた簡潔なタイトルが表示されるので、適切なものを素早く見つけて再適用できます。

# コミットの説明：オンデマンドでサマリーを取得

{{<screenshot alt="SmartGit 25.1 AIコミット説明機能 - コミット詳細ビューでサマリーを表示" src="ai-explaining.png">}}

---

素早くキャッチアップしたいですか？SmartGitに変更内容を説明させましょう。

* **右クリック &gt; コミットを説明** -- 選択したコミットの簡潔な**サマリー**を生成します。
* **マルチコミット、同時処理** -- 複数のコミットを選択してExplainを実行。SmartGitがバックグラウンドですべての説明を生成し、結果を**Git Notes**に保存します。
* **差分を考慮した説明** -- コミットメッセージと差分を使用して、意図と主要な変更点を強調します。

{{< link url="https://docs.syntevo.com/SmartGit/Latest/Manual/GUI/AI-Commit-Annotations" display="詳細を見る" >}}

# プライバシーファースト、設計による

{{<screenshot alt="SmartGit 25.1 AIプライバシー同意ダイアログ - データ送信前に明示的なユーザー承認を確保" src="ai-consent.png">}}

---

一部のツールはAIを呼び出すとすぐにプロジェクトデータをアップロードします。**SmartGitはそうしません。** 明示的に許可した場合にのみ、**選択したプロバイダー**にデータを送信します。

* **明示的なオプトイン** -- リポジトリとプロバイダーごとの最初のAIリクエスト時に同意ダイアログが表示されます。承認するまで何もアップロードされません。
* **きめ細かな制御** -- いつでも後から取り消したり、グローバルに無効にしたりできます。必要に応じてプロバイダーを切り替えられます。
* **制限と透明性** -- **差分コンテキストサイズ**を設定し、**最大差分サイズ**を制限し、**デバッグログ**を有効にして、送信される内容を正確に確認できます。

# あなたのAI、柔軟なプロンプト、Git Notes

SmartGitは**お好みのAI**に接続します。
人気のクラウドプロバイダーや社内の**オンプレミス**LLMを選び、一度設定すれば、すべてのAIアプリケーションで使用できます。

**柔軟なプロンプト**でトーンを調整し、メッセージがチームから発信されたかのように読めるようにします。
結果を**Git Notes**として保存することで、重要な場所に保持できます -- コミットに添付され、グラフに表示され、チームメイトと簡単に共有できます。

# Git Notes：ファーストクラスで設定可能

{{<screenshot alt="SmartGit 25.1 Git Notesインターフェース - 名前空間選択とログラフでのノートインジケーター" src="git-notes.png">}}

---

 **Git Notes**は、コミットを変更せずに添付できるメタデータです。

 * **名前空間を選択** -- **refs/notes/**カテゴリと、ノートが**ログラフ**でどのように表示されるかを選択します。
 * **UIで作業** -- ノートを追加、表示、編集できます。コミット詳細とグラフに表示されます。
 * **共有と自動化** -- リポジトリと一緒にノートをプッシュ/フェッチし、AIの説明をノートとして保存します。

{{< link url="https://docs.syntevo.com/SmartGit/Latest/Manual/GUI/Notes" display="詳細を見る" >}}

# ワークツリー：よりスムーズで安全に

{{<screenshot alt="SmartGit 25.1 インテリジェントなワークツリー切り替え - チェックアウト済みブランチの既存ワークツリーを自動的に開く" src="worktree-switch.png">}}

---

Gitのワークツリー機能のサポートがいくつかの点で改善されました：

* **一目で確認** -- 独自のワークツリーを持つブランチがログラフでマークされます。
* **スマートなチェックアウト** -- ブランチが別の場所で既にチェックアウトされている場合、Checkoutはそのワークツリーを開きます。
* **UIで管理** -- スタンダードウィンドウに新しい**追加**、**削除**、**プルーン**コマンド。
* **落とし穴を防止** -- 不明または無効なワークツリーを早期に検出します。
* **正確なステータス検出** -- リベースまたはバイセクト中のワークツリーのブランチ検出の修正。

# オクトパスマージ

{{<screenshot alt="SmartGit 25.1 オクトパスマージの視覚化 - 複数の親ブランチを持つコミット" src="octopus-merge.png">}}

---

**オクトパスマージコミット**は、**3つ以上の親**を持つマージコミットです。
これらは、**複数のブランチ**を直接（現在のブランチに）**マージ**するか、
マージをマージコミットに**修正コミット**することで作成できるようになりました。

# SmartGitを認証ヘルパーとして使用

{{<screenshot alt="SmartGit 25.1 認証ヘルパー設定 - Gitコマンドライン統合用の環境設定" src="smartgit-as-credential-helper.png">}}

---

SmartGitは、環境設定の**実行ファイル**ページで、SmartGitから呼び出されるすべてのコマンドの**認証ヘルパー**として動作するように設定できます。

さらに、**シェルスクリプト**、他のアプリケーション、または**Gitコマンドライン**用の認証ヘルパーとしてSmartGitを使用することも可能です -- そのような用途のために認証を個別に設定する必要はありません。
リポジトリを**クローン**する際にこのオプションを直接選択するか、後から**リポジトリ設定**で有効にできます。

# 強制プッシュ：適切なポリシーを選択

{{<screenshot alt="SmartGit 25.1 強制プッシュポリシー設定 - ブランチ固有の安全制御" src="forced-push-options.png">}}

---

強制プッシュの処理には3つのオプションがあります。
ワークフローに合ったものを選択してください。

* **強制プッシュを許可しない** -- 履歴を変更してはいけない共有または規制されたプロジェクトの保護された**メインライン**ブランチ（例：`main`、`release`）に最適。
* **フィーチャーブランチへの強制プッシュを許可（推奨）** -- 短命のフィーチャーブランチがマージ前にリベースまたはスカッシュされる**Feature Flow/Git Flow**に理想的。メインラインブランチを保護しながら、コントリビューターが履歴を整理できます。
* **すべてのブランチへの強制プッシュを許可** -- 共有履歴の安全性よりも最大限の柔軟性が重要な、ソロリポジトリ、スクラッチフォーク、または実験的な作業に適しています。

# 異なる作者のコミットをスカッシュ

{{<screenshot alt="SmartGit 25.1 コミットのスカッシュ - コントリビューターのクレジットを保持する共著者属性" src="squash-commits-co-authors.png">}}

---

クレジットを失うことなく、異なる作者の複数のコミットをスカッシュします。
結果のコミットの**作者**を選択し、**共著者を追加**を使用して他のすべての作者に`Co-authored-by:`行を挿入します。

共同作業が適切に帰属されるように、小さなヘルパーが連携します：

* **ログ &gt; 詳細** -- コントリビューターの`name <email>`をコピーして、必要な場所に貼り付けます。
* **作者を編集** -- 著者を設定する際に`name <email>`を素早く貼り付けます。

# LFS改善：より明確な状態、高速なリフレッシュ

{{<screenshot alt="SmartGit 25.1 LFSファイルステータス表示 - 明確なバッジで未展開ポインターファイルを表示" src="lfs-unexpanded.png">}}

---

SmartGit 25.1は問題のあるLFSステータスを明確にし、一般的な操作を高速化します。

* **未展開ファイルを確認** -- ファイルビューはポインターファイルに**LFS: 未展開**バッジを表示し、オブジェクトが展開されていない場合（例：LFSがインストールされていない場合）にすぐに気づくことができます。
* **便利なツールチップ** -- **ファイル**は**LFS不整合**エントリにツールチップを表示し、何が問題でどう修正するかを説明します。
* **高速なリフレッシュ** -- **LFSリフレッシュ**が大きなファイルを持つリポジトリで高速化されました。

# *すべてのブランチ + タグ*でのリモート管理

{{<screenshot alt="SmartGit 25.1 すべてのブランチ + タグビューでのリモート管理 - 包括的なリモート操作" src="all-branches-tags-remotes.png">}}

---

**すべてのブランチ + タグ**から直接**リモートにアクセスして管理**できるようになりました。
コンテキストメニューを使用して、ブランチやタグと一緒にリモートを操作します。

* **フェッチ** -- マージせずにリモート参照を更新します。クイックで選択的な更新に最適です。
* **名前変更** -- リモートのローカル名を変更します（例：`origin`を`myhost`に）。関連するブランチも含め、他に影響を与えません。
* **削除** -- リモートのローカル追跡を削除します。いつでも再追加できます。
* **URLをコピー** -- 共有やスクリプト用にリモートURLをクリップボードにコピーします。
* **プロパティ** -- リモートのURLと関連設定を表示または編集します。

**ヒント：** フィルターボックスに**remote**と入力すると、すべてのリモートをすばやく表示できます。

{{<screenshot alt="SmartGit 25.1 スタンダードウィンドウのプルリクエストフィルタリングオプション - 集中したワークフロー管理" src="std-pull-requests.png">}}

**プルリクエスト**の表示をカスタマイズできるようになりました。

# マイヒストリー：フォーカスしたリベース表示

{{<screenshot alt="SmartGit 25.1 マイヒストリーでのフォーカスしたリベース表示 - リベース中は関連するコミットのみを表示" src="focused-rebasing-display.png">}}

---

**リベース**中は、異なるコミットやブランチについて混乱しやすくなります。
複数のローカルブランチがある場合は特に重要です。

これを克服するため、**マイヒストリー**はリベースモード中に**関連のないブランチ**を非表示にし、**リベースに関連するコミット**のみを表示するようになりました。

非表示のブランチにアクセスする必要がある場合（例：コミットを**チェリーピック**する場合）は、一時的に**すべてのブランチ + タグ**を使用してください。

# 破棄が完全な名前変更の取り消しと追跡されていないファイルの削除に対応

{{<screenshot alt="SmartGit 25.1 強化された破棄機能 - 名前変更を元に戻し、追跡されていないファイルをクリーンアップ" src="discard-delete-untracked-file.png">}}

---

1つのコマンドでクリーンアップ。

* **名前変更されたファイル** -- 破棄はファイルを**元の名前とパス**に復元し、ローカルの編集を破棄して、ワーキングツリーをHEADに一致させます。
* **追跡されていないファイル** -- 破棄で（確認付きで）**削除**できるようになりました -- 保持したくない生成ファイルや一時ファイルに便利です。

# ワークツリー、トラッキング設定、プッシュ先のコマンド追加

{{<screenshot alt="SmartGit 25.1 スタンダードウィンドウのブランチ管理コマンド - トラッキングと公開" src="new-commands.png">}}

---

SmartGit 25.1では、**マイヒストリー**と**すべてのブランチ + タグ**に、ログやワーキングツリーウィンドウで知っているかもしれないブランチコマンドが追加されました。

* **プッシュ先...** -- 現在のブランチを特定の**リモート/ブランチ**にプッシュするか、そこに新しいものを作成します。フィーチャーを**アップストリーム**やフォークに公開する場合、または一回限りのターゲットが必要な場合に最適です。通常の**プッシュ**とは異なり、単一のリモートをターゲットにし、正確な参照を選択できます（必要に応じて強制も可能）。
* **トラッキングブランチを設定...** -- ローカルブランチを正しい**アップストリーム**ブランチに向けて、**プッシュ/プル**が行き先を知り、UIが**ahead/behind**を表示できるようにします。ブランチの名前を変更したり、リモートを切り替えたりした場合に使用します。
* **トラッキングを停止...** -- アップストリーム設定を削除して、ブランチがリモートに結び付けられなくなります。リモートブランチが削除された場合や、次回プッシュ時に新しい名前/リモートで公開したい場合に便利です。

これらのオプションにより、UIを離れることなくブランチの公開、再ターゲット、クリーンアップが簡単になります。
