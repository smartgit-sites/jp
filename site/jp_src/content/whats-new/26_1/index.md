SmartGit 26.1 では、UI が大きく刷新され、グラフとワークツリーのワークフローもよりわかりやすくなります。主な改善点は次のとおりです。
- 作り直されたアイコン、比較表示の色、ダークテーマの改善による新しい外観
- Git 3.0 に向けた SHA-256 リポジトリと reftable ref のサポート
- 標準ウィンドウでの新しい GitLab サポート。マージリクエスト、CI、GitLab で開く操作、Issue ベースのコミットメッセージに対応
- ワークツリーの表示、同期、グラフ操作の改善
- Commit Overlap
- SmartGit の各メインウィンドウを見つけやすくする改善
- カスタム Ask AI プロンプト、`{{ branch }}` テンプレート、マージコミットの AI サポート
- 標準ウィンドウとログウィンドウでのプロバイダー設定の見直し
- 複数リモートのリポジトリでの Pull 動作の明確化

***

# UI の刷新

{{<screenshot alt="SmartGit 26.1 の色分けが明確な新しいアイコンセット" src="reworked-icon-set.png">}}
{{<screenshot alt="ダークテーマが改善されました" src="dark-theme.png">}}
{{<screenshot alt="SmartGit 26.1 のより見やすくなった比較表示の色" src="reworked-compare-colors.png">}}

---

SmartGit 26.1 では、見た目が大きく刷新されます。
よりモダンな外観になり、視覚的な意味づけが明確になり、ライトテーマとダークテーマの一貫性も高まりました。

**作り直されたアイコンセット**

アイコンセットは全面的に作り直されました。
よりモダンな見た目になり、色数を絞ったうえで、ライトテーマとダークテーマ向けのバリエーションが用意されています。

* **すっきりした外観** -- よりモダンな形状と、絞り込まれた意図的なカラーパレット。
* **コントラストの向上** -- ライト用とダーク用の専用バリエーションにより、どちらのテーマでも識別しやすくなります。

**改善されたダークテーマ**

ダークテーマはさらに洗練されました。

* **全体的により暗い外観** -- 背景の色調が深くなり、白っぽさが抑えられました。
* **テーマに合ったアイコンバリエーション** -- 新しいアイコンセットには、ダークテーマ専用版が含まれています。

**比較表示の色を見直し**

ファイル比較では、よりなじみのある色分けが使われるようになりました。

* **変更済み = 黄色** -- 変更されたブロックは一目で認識しやすくなります。
* **追加 = 緑色** -- 追加された内容は、多くのユーザーが期待する色で強調表示されます。
* **削除済み = 赤** -- 削除された内容が以前よりも自然に目立ちます。

# Git 3.0 との互換性

{{<screenshot alt="reftable ref 形式を使用した SHA-256 リポジトリとの Git 3.0 互換性" src="git-3.0.png">}}

---

Git は **SHA-256** オブジェクト ID と **reftable** ref に向けて進化しています。
SmartGit 26.1 はその移行の準備ができています。

* **SHA-256 リポジトリ** -- SmartGit は、Git の新しいオブジェクト形式を使用してリポジトリを操作できます。
* **Reftable のサポート** -- 新しい ref ストレージ バックエンドもサポートされています。

# 標準ウィンドウの GitLab

{{<screenshot alt="GitLab 連携、Browse メニュー、リポジトリ詳細を表示した標準ウィンドウ" src="gitlab.png">}}

---

標準ウィンドウで、既存の GitHub サポートと同等の GitLab サポートを利用できるようになりました。

* **GitLab マージリクエスト** -- マージリクエストは標準ウィンドウのワークフローに統合されています。
* **My History での GitLab CI** -- マージリクエスト、ブランチ、分岐したリモートについて、CI パイプラインの状態が表示されます。
* **GitLab で開く** -- アクティブなブランチやリポジトリを、**Browse** ボタンから GitLab で直接開けます。
* **GitLab Issue からコミットメッセージを作成** -- 選択した GitLab Issue からコミットメッセージを作成できます。

# ブランチとグラフでのワークツリー状態

{{<screenshot alt="ワークツリーに接続されたブランチとそのワークツリーの状態を示すブランチとグラフ" src="worktrees.png">}}

---

ワークツリーに紐づいたブランチが、現在のワークツリー状態とともに **Branches** と **Graph** に表示されるようになりました。

* **現在のワークツリー状態を一目で確認** -- ref は、紐づいたワークツリーがクリーンか変更済みかを示し、ツールチップには関連するワークツリーのパスを表示できます。
* **開いているワークツリーリポジトリを同期** -- 関連する開いたワークツリーリポジトリはすぐに更新されるため、**Branches** と **Graph** も最新の状態に保たれます。
* **よりスムーズなグラフ操作** -- 「ワークツリーへ切り替え」ダイアログを無効にでき、クリーンなワークツリー ref をグラフ内でドラッグできます。

# Commit Overlap

{{<screenshot alt="オーバーラップ状態を示す Commit Overlap 列を含むグラフ" src="overlap.png">}}

---

**Commit Overlap** は、グラフに新しい観点を追加します。**Overlap** 列は、あるコミットが、選択中または固定された比較対象のコミットとどの程度重なっているかを示します。
これにより、関連するコミットを見つけ、並べ替えやスカッシュの候補を判断し、上流で競合が起きる可能性に早めに気づきやすくなります。

* **重なりのカテゴリ** -- SmartGit は、重なりなし、軽い重なり、大きな重なり、サブセット、スーパーセット、同じ変更ファイルを区別します。
* **ツールチップの詳細** -- ツールチップには、共通するファイルや潜在的な競合を表示できます。

# 他の SmartGit ウィンドウを見つける

{{<screenshot alt="メイン ウィンドウ間を切り替えるための SmartGit 26.1 Discover ダイアログ" src="discover.png">}}

---

SmartGit の 3 つのメインウィンドウは見た目が似ているため、別のウィンドウを開いてしまい、なぜ UI が急に違って見えるのか戸惑うことがありました。現在どのメインウィンドウを開いているのか、他のウィンドウへどう移動するのかも、一目では必ずしも明らかではありませんでした。

各ウィンドウには、認識しやすく区別しやすい専用アイコンが付きました。SmartGit 26.1 では、現在のウィンドウがわかりやすくなり、他の 2 つのウィンドウも右上から見つけやすくなります。その結果、**現在位置が明確になり**、**混乱が大きく減り**、違うウィンドウを開いた場合でも**簡単に切り替えられます**。

# Ask AI、プロンプトテンプレート、言い換え

{{<screenshot alt="選択したコミットに対するカスタム プロンプトを含む AI ダイアログに質問する" src="ask-ai.png">}}

---

SmartGit 26.1 では、AI ワークフローが 3 つの重要な点で拡張されます。

* **カスタムプロンプトで Ask AI を実行** -- 例えばフィーチャーブランチの最終確認として、選択した複数のコミットにユーザー定義のプロンプトで **Ask AI** を実行できます。
* **より柔軟なプロンプトテンプレート** -- コミットメッセージ生成、言い換え、**Ask AI** が `{{ branch }}` プレースホルダーをサポートします。テンプレートでは `@ai-marker` を使用でき、そのマーカーだけが LLM の応答に置き換えられます。
* **マージコミットと署名付きコミット** -- **Ask AI** がマージコミットでも動作するようになり、AI による言い換えでは署名付きコミットの署名が保持されます。

# 標準ウィンドウとログウィンドウのプロバイダー設定

{{<screenshot alt="複数の GitHub アカウントを切り替えるためのプロバイダー構成セレクター" src="provider-rework.png">}}

---

**標準**ウィンドウと**ログ**ウィンドウで、複数のプロバイダーアカウントを扱う操作がよりわかりやすくなりました。

* **明示的に切り替え** -- アクティブなプロバイダー設定を UI で直接選択できるため、現在どのアカウントまたはサイトを使っているかが明確になります。
* **リモートごとの選択** -- プロバイダー設定はリモート単位でも選択できます。

# Pull と Pull All (標準ウィンドウ)

{{<screenshot alt="標準ウィンドウでは、[プル] ツールバー ボタンのポップアップ メニューでプル動作を構成できます。" src="std-pull-all.png">}}

---

複数リモートのリポジトリで、Pull の動作がより明確になりました。

* **デフォルトを直接選択** -- Pull が現在のリモートを使うか、すべてのリモートを使うかを、ツールバーのポップアップから設定できます。
* **フェッチ後の制御を強化** -- Pull 後にマージ済みブランチを削除するかどうかを選べるようになりました。
